For selected title generation/runtime work (009–014):

- **Indirect targets:** private `flow_scan.unresolved_indirect_sites` records every noncanonical LR/CTR word. Main `.text` has Campaign 2,285 CTR / 1,290 LR sites and Multiplayer 2,647 CTR / 1,363 LR sites. Some are conditional returns or embedded data, not necessarily calls. Classify link/condition/reachability and enforce reviewed executable bounds at runtime; do not infer target coverage from site count.
- **Switches:** all five independently verified absolute tables per module are BINK-only. None establish main-engine coverage. The independent check's bounded range evidence is not a dominance proof. Compare main-engine analysis capabilities and unresolved-target diagnostics between candidates.
- **Exceptions:** `nonlocal_flow.unresolved_exception_function_entries` enumerates all 310 Campaign / 322 Multiplayer handler-bearing entries. No scope tables, unwind actions or host exception implementation are certified. Retain diagnostic failure until a verified implementation exists.
- **Nonlocal exits:** `nonlocal_flow.services` records three direct-call words to `RtlUnwind` and one to `RtlCaptureContext` per image, with containing `.pdata` ranges. Use these to navigate; do not set longjmp/setjmp addresses from adjacency or names alone. Their status remains unverified.
- **Functions:** `.pdata` covers declared ranges, not all code. 3,593 / 3,677 distinct direct-call targets remain outside declared `.pdata`/helper/import entries; these are candidates, not automatically trusted leaf functions. Generation must fail diagnostically on unreviewed boundaries/targets rather than manufacturing coverage.
- **Imports:** 258 / 262 function pairs and 13 data variables per module have name-table identities. Runtime implementations, variables' layouts/lifetimes, version compatibility and dynamic symbol lookup are unverified. Handle identity, function and variable imports distinctly; arbitrary pointers are not support.
- **Helpers:** eight complete ladders per image have unique matches and independent instruction decoding. Possible entries preceding register 14 are unassigned. Revalidate against the selected runtime's register/context model before generating native functions.

Unknowns are deliberately retained in private machine-readable inventories. Exhaustive static resolution is not a prerequisite for comparing bounded runtime slices; it remains a correctness gate for any slice that attempts to execute those paths. Real-title execution and mode parity require their own evidence.
