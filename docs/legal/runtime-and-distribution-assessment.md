## Steamworks and NVIDIA boundaries

Valve explicitly warns that copyleft combinations with Steamworks may be incompatible, while listing permissive licenses as generally acceptable. The app operator must possess the necessary rights; the upstream runtime cannot grant Valve permissions it does not own. Our present GPL-only code and copied GPL runtime code must remain part of that assessment. [Valve's open-source distribution guidance](https://partner.steamgames.com/doc/sdk/uploading/distributing_opensource?l=english).

Public documentation describes runtime API redistributables such as `steam_api64.dll`; that is not permission to mirror the entire SDK, headers or a borrowed game's identity. Obtain the authorized AppID/SDK terms and version, review the selected redistributables, and verify account/application access in MW3-019. No SDK agreement has been accepted, account enrolled or AppID borrowed by this assessment. [Steamworks API deployment](https://partner.steamgames.com/doc/sdk/api?l=english).

Valve's public networking code is distinct from service authorization. SDR and native friend/lobby integration still require the applicable authorized Steam setup and real relay testing; an open-source transport does not grant access. Planned RecompLauncher delivery does not change service requirements or guarantee Steam-store approval. [Valve's networking overview](https://partner.steamgames.com/doc/features/multiplayer/networking?l=english), [SDR documentation](https://partner.steamgames.com/doc/features/multiplayer/steamdatagramrelay?l=english).

At Streamline pin `625db07d4bca5abc67d781c42af7e7fb0761f1b6`, framework `license.txt` grants MIT terms **with explicitly separately licensed Nsight files**. Its presence does not put all feature SDKs/DLLs under MIT. The pinned [NGX/RTX SDK license](https://github.com/NVIDIA-RTX/Streamline/blob/625db07d4bca5abc67d781c42af7e7fb0761f1b6/external/ngx-sdk/license.txt) has object-code distribution conditions, authorized-user terms and a restriction against making the SDK subject to conflicting open-source obligations. The pinned Vulkan [Reflex license](https://github.com/NVIDIA-RTX/Streamline/blob/625db07d4bca5abc67d781c42af7e7fb0761f1b6/external/reflex-sdk-vk/reflex.license.txt) has its own agreement and designated-distributable conditions. Nsight developer components have separate terms. None is approved here for bundling with our GPL program.

Keep NVIDIA feature source, wrappers, support DLLs and developer utilities as separate package entries with their own versions/hashes/license notices. No optional binary is automatically permitted because a CMake install target copies it. SDK acceptance, final redistribution conditions and GPL compatibility remain release blockers for those features. Preserve a feature-free native renderer path while these questions are resolved; do not reverse engineer vendor SDKs or patch their technical restrictions.

## Decision and handoff

Both candidates remain eligible for **bounded local research**, with proprietary features disabled and all original inputs private. ReXGlue's separation of host codegen from runtime is promising for maintainability and license flexibility, but neither a legal clearance nor a performance result. The GPL-only MW2 runtime needs a particularly explicit compatibility path for the requested proprietary SDK integrations. No candidate wins on licensing labels alone.

For MW3-008, freeze actual transitive inputs and keep generated title code private; log changes and unimplemented behavior. ReXGlue's pinned build requires Clang 20+ / C++23 and Vulkan SDK evidence at its declared minimum, unlike our Clang 18 CPU-tool preparation. Use an isolated additional toolchain; do not mutate the working preparation pin to make comparisons appear reproducible. Resolve compiler/library/SDK availability during the bounded build spike.

For MW3-019/031 and feature work: review account/SDK agreements with an authorized owner, settle the selected adapter/runtime licensing, resolve questionable file provenance or replace those files, produce the real link graph/SBOM and LGPL relink plan, and review every final package entry. These unresolved items are recorded release dependencies, not an excuse to block unrelated private bringup or to silently drop Steam/DLSS goals.

Assessment validation: checked pinned roots, relevant per-file notices and build edges; inspected all declared ReXGlue submodule license locations (including TLSF's header); recorded immutable source/blob evidence; reviewed the proposed package against the matrix. A read-only tree comparison requires all 15 component pins to match the declared parent gitlinks exactly, with license evidence for each. No counsel opinion, distributor rights grant, SDK authorization or completed-package audit is represented.
